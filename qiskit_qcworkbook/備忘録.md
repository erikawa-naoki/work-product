# 備忘録
## Qiskit導入

### Pythonのインストール(Anaconda Navigatorの導入)

-Qiskitの導入にはPythonの仮想環境が必要だがWindowsの場合面倒なのでAnacondaを利用する.  
 i. [Anacondaのダウンロードリンク(メールアドレスが必要)はこちら.](https://www.anaconda.com/download)  
 ii. ダウンロード後適当にPythonのバージョンを選択して仮想環境構築(Python3.7以降)  
 iii. [IBMのInstall Qiskitに沿ってターミナルでコマンドを実行する.](https://quantum.cloud.ibm.com/docs/en/guides/install-qiskit)  
 iv. Visual Studio CodeにJupyterとPythonの拡張機能を導入する.  
 v. Visual Studio Codeで.ipynb形式のファイルを作成(または開き),2と3で作成したカーネルを選択することで実行が可能になる.

## Qiskit2.0以降のqc_workbook廃止の対処法について  

- Qiskit2.0以降ではqc_workbookが廃止されているため,ワークブックをそのまま実行した場合エラーが発生する.  
 - qc_workbookのソースファイルをGitHub上からダウンロードし,PYTHONPATHを通す必要がある.  
 - [qc_workbookのGitHubリンクはこちら](https://github.com/UTokyo-ICEPP/qc-workbook)  
 - [PATHの通し方はこちら(仮想環境でも同様に実行すればOK).](https://qiita.com/maech/items/72559402556eb2af73ad)  
  - [import error時に表示されるsys.pathについて知りたければこちら,読まなくてもOK.](https://qiita.com/mei2678/items/53da7818e03722b451b2)  

## c_if()メソッドの廃止とその代替(if_test()メソッド)  

- Qiskit2.0以降ではc_if()メソッドが廃止され,その代替にif_test()メソッドが存在する.  
- [if_test()のIBMのドキュメントはこちら.](https://quantum.cloud.ibm.com/docs/en/api/qiskit/qiskit.circuit.QuantumCircuit)  
- [使用にはwith構文が必要になる(with構文の説明リンク).](https://zenn.dev/k41531/articles/9c566a778b79ca)
